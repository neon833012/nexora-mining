# NEON MINING - Web3 Cryptocurrency Cloud-Mining Platform

> High-end, interactive Web3 cloud-mining platform featuring real-time hashrate visualization, 365-day compounding projections calculator, BEP-20 rewards dashboard, interactive neural mesh ("Mayajal"), and 3-level referral network.

---

## 🚀 Key Highlights & Pitch Features

1. **Futuristic Cyber-Web3 UI**:
   - Built specifically with a high-end mobile-first aesthetic (`max-w-[430px]` view on desktop, full mobile layout on phones).
   - Deep Obsidian canvas (`#030712`), glassmorphic navy cards (`#0C1424`), and neon accents (Cyan `#00F0FF`, Gold `#FBBF24`, Emerald `#10B981`).

2. **Dual Interactive HTML5 Canvas Animations**:
   - **Interactive Mayajal Background**: 40 drifting constellation nodes, dynamic proximity connecting lines, moving energy packets, and **touch/mouse magnetism** that pulls nodes towards your finger/cursor with electric arcs and shockwave ripples.
   - **NEON Core 3D Orbital Visualizer**: 3 concentric orbital rings with counter-rotating multi-color satellites, central glowing core sphere with 3-tier diamond blockchain stack, and 4 directional telemetry badges (`USDT`, `NODES`, `BLOCKS`, `HASHRATE · 428.5 TH/s`).

3. **Interactive 365-Day Yield Calculator**:
   - Real-time yield simulation with USDT amount inputs and 5 quick preset buttons.
   - Duration slider (`1` to `365` days).
   - Daily compounding toggle with dynamic **HTML5 Canvas growth chart** displaying exponential compounding curve (`37.78x`) vs linear yield curve (`1.0%/day`).

4. **5 Allocation Plans with 365D Math**:
   - Plan 01 (20 USDT) to Plan 05 Elite (350 USDT).
   - Expandable breakdown calculating Day 1 yield, simple total, compound reinvestment total, and compound advantage.
   - One-click plan activation dialog with live balance updates.

5. **Live Dashboard & Financial Flows**:
   - 6 Glass metric cards: Total Balance, Active Mining Power, Today's Projected Reward, Total Rewards, Referral Income, Available Withdrawal.
   - 24-hour mining task synchronization cycle.
   - Demo wallet funding simulation (BEP-20).
   - Full withdrawal flow with 5% fee calculation and minimum 3 USDT rule.
   - Live rolling blockchain block ticker (`#34912882+` auto-advancing every 5 seconds).

6. **Network & Credibility**:
   - 3-level referral system (L1 10%, L2 5%, L3 2%) with canvas node diagram and 1-click clipboard copy.
   - 12-item FAQ accordion with smooth expand/collapse.
   - 6 security and transparency pillar cards.
   - Regulatory risk disclosure alert box.
   - Contact form with support dispatch simulation.

---

## 💻 Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **Visuals & Graphics**: HTML5 2D Canvas API (60fps dynamic physics & trig math)
- **Deployment & Edge**: Cloudflare Pages, Wrangler, Cloudflare Quick Tunnels

---

## 🛠 Getting Started

### Development
```bash
npm install
npm run dev
```
Local dev server runs at `http://localhost:3000/`.

### Cloudflare Quick Tunnel (Mobile Preview)
```bash
npm run tunnel
```
Instantly generates a public HTTPS link on `*.trycloudflare.com` to test on any mobile phone.

### Production Build
```bash
npm run build
```

### Cloudflare Pages Deployment
```bash
npm run deploy:cf
```
